# G10 FX Regime Detector

A Streamlit application that uses a **Gaussian Hidden Markov Model** to classify the macro environment into distinct regimes — *Risk-On*, *Transitional*, *Risk-Off* — then evaluates how G10 FX pairs have historically performed in each regime.

## Two Data Modes

| | 📊 Market Indicators | 🏛️ Macro Indicators |
|---|---|---|
| **Source** | Yahoo Finance | FRED API |
| **Frequency** | Daily | Monthly |
| **Features** | VIX, S&P 500 returns, 10Y yield, gold, USD index, FX vol | CPI, unemployment, NFP, industrial production, Fed Funds, yield curve, consumer sentiment |
| **Regime sorting** | Average VIX | Average unemployment |
| **Best for** | Tactical FX positioning (weeks) | Strategic cycle identification (quarters) |
| **Ideal start date** | 2015 | 2000 |

The toggle in the sidebar switches between modes.  The same HMM engine runs underneath — what changes is the data pipeline and the features feeding it.

## Features

- **Regime classification** — detects 2–4 macro regimes from seven cross-asset or macro features
- **Real-time assessment** — current regime, confidence level, switching probability
- **FX performance analysis** — average forward returns for each G10 pair by regime
- **Regime fingerprints** — radar chart comparing feature profiles across regimes
- **Per-regime correlation matrices** — how feature co-movements shift between environments
- **Transition dynamics** — probability of moving between regimes, average and max durations

## Model Inputs

### Market Mode
| Feature | Source | Captures |
|---------|--------|----------|
| VIX level | CBOE | Implied volatility / fear |
| VIX 5-day change | CBOE | Direction of fear |
| S&P 500 21-day return | S&P | Equity risk appetite |
| 10Y yield 21-day change | UST | Rate direction |
| USD index 21-day return | G10 crosses | Dollar strength |
| Gold 21-day return | COMEX | Safe-haven demand |
| G10 FX realised volatility | G10 crosses | Currency choppiness |

### Macro Mode
| Feature | FRED Code | Captures |
|---------|-----------|----------|
| CPI YoY | CPIAUCSL | Inflation regime |
| Unemployment rate | UNRATE | Labour market slack |
| NFP monthly change | PAYEMS | Labour momentum |
| Industrial production YoY | INDPRO | Real economy growth |
| Fed Funds rate | FEDFUNDS | Monetary policy stance |
| 10Y–2Y spread | T10Y2Y | Yield curve / recession signal |
| Consumer sentiment | UMCSENT | Demand confidence |

## Methodology

**Gaussian Hidden Markov Model** (Hamilton, 1989): observable market or macro features are assumed to be generated by a latent (hidden) state.  The HMM learns emission distributions (what each regime "looks like"), transition probabilities (likelihood of switching), and the most probable state sequence.  Regimes are auto-labelled by sorting on average VIX (market mode) or average unemployment (macro mode).

## Getting Started

```bash
git clone https://github.com/kavishetty0402/g10-fx-regime-detector.git
cd g10-fx-regime-detector
pip install -r requirements.txt
streamlit run app.py
```

For **Macro mode**, you need a free FRED API key — register at [fred.stlouisfed.org](https://fred.stlouisfed.org/docs/api/api_key.html) (30 seconds).  Enter the key in the sidebar, or store it in `.streamlit/secrets.toml`:

```toml
FRED_API_KEY = "your_key_here"
```
