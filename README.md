# G10 FX Regime Detector

A Streamlit application that uses a **Gaussian Hidden Markov Model** to classify the macro environment into distinct regimes — *Risk-On*, *Transitional*, *Risk-Off*, and others — then evaluates how G10 FX pairs have historically performed in each regime.

## Overview

Currency markets behave fundamentally differently depending on the prevailing macro environment. Carry trades (long high-yielding AUD/NZD, short JPY/CHF) generate steady returns in calm, risk-on periods but unwind sharply in crises. This tool systematically identifies the current regime from observable cross-asset indicators and maps out which G10 FX trades have historically worked in that environment.

### Features

- **Regime classification** — detects 2–4 macro regimes from seven cross-asset features
- **Real-time assessment** — identifies the current regime with a confidence level and switching probability
- **FX performance analysis** — average forward returns for each G10 pair by regime
- **Transition dynamics** — probability of moving between regimes, average and max regime durations
- **Interactive timeline** — regime-coloured bands overlaid on any G10 FX pair

### Model Inputs

| Feature | Source | Captures |
|---------|--------|----------|
| VIX level | CBOE | Implied equity volatility / fear |
| VIX 5-day change | CBOE | Direction of fear |
| S&P 500 21-day return | S&P | Equity risk appetite |
| 10Y yield 21-day change | UST | Rate direction |
| USD index 21-day return | G10 crosses | Dollar strength |
| Gold 21-day return | COMEX | Safe-haven demand |
| G10 FX realised volatility | G10 crosses | Currency market choppiness |

### Methodology

The model is a **Gaussian Hidden Markov Model** (Hamilton, 1989) — a statistical model that assumes observable market features are generated by a latent (hidden) state. The HMM learns:

1. **Emission distributions** — what each regime "looks like" in terms of the seven features
2. **Transition probabilities** — likelihood of switching between regimes on any given day
3. **State sequence** — which regime is most probable on each historical date

Regimes are auto-labelled by sorting on average VIX: the lowest-VIX state is assigned *Risk-On*, the highest *Risk-Off*.

## Getting Started

### Prerequisites

- Python 3.9+
- pip

### Installation

```bash
git clone https://github.com/kavishetty0402/fx-regime-detector.git
cd fx-regime-detector
pip install -r requirements.txt
```

### Running locally

```bash
streamlit run app.py
```

### Deploy on Streamlit Cloud

1. Push to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Point to your repo and `app.py`
4. Deploy
